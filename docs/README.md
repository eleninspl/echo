# Echo docs

Echo finds podcast guests in the sweet spot: people a show's audience will love, who bring a new audience that will love the show back. It is our entry to the Qloo Agentic Hackathon 2026.

| [qloo-map.md](qloo-map.md) | Every Qloo API feature, whether it works on the hackathon server, and what Echo could use it for |
| [plan.md](plan.md) | v1: what we build by the 27 Oct freeze, the engine tasks split in two, dates |
